Conic 0.2.0

Conic is the VLC 3 player with the interface redesigned after the
[VLC Redesign](https://www.figma.com/community/file/1691465999134370980/vlc-redesign)
Figma Community file by [Juxtopposed](https://www.youtube.com/@juxtopposed).
Playback runs on VLC 3.0.24, which is bundled in each download.

This release follows the two previews. What they added is described in the
[0.2.0-preview.1](https://github.com/mfkl/conic/releases/tag/v0.2.0-preview.1) and
[0.2.0-preview.2](https://github.com/mfkl/conic/releases/tag/v0.2.0-preview.2) notes.

## What's fixed

- Continue where you left off works when a file takes a moment to open. Conic dropped the saved position (no prompt, or Always started from the beginning) when VLC reported the file playing before it knew its length.

## Downloads

| File | Platform |
| --- | --- |
| `Conic-0.2.0-win-x64.zip` | Windows 10 and 11, x64 |
| `Conic-0.2.0-osx-arm64.zip` | macOS on Apple silicon |
| `Conic-0.2.0-osx-x64.zip` | macOS on Intel |
| `Conic-0.2.0-linux-x64.tar.gz` | Linux x64, glibc 2.38 or later (Ubuntu 24.04, Debian 13, Fedora 39) |

These builds are not signed.

- **Windows:** unzip anywhere and run `Conic.exe`. If SmartScreen stops it, choose **More info**, then **Run anyway**.
- **macOS:** unzip, move `Conic.app` to Applications, try to open it once, then choose **Open Anyway** in **System Settings > Privacy & Security**, or run `xattr -dr com.apple.quarantine /Applications/Conic.app` once in Terminal.
- **Linux:** extract the archive and run `./Conic`.

SHA-256 checksums are in `SHA256SUMS.txt`.

## Known limitations

- Missing VLC 3 features are listed in [Feature parity with VLC 3](https://github.com/mfkl/conic/blob/main/docs/FEATURE_PARITY.md).
- While a button has keyboard focus, keyboard shortcuts are ignored. Click the video first.
- Subtitles do not show in Home's mini player.
