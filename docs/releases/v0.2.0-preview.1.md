Conic 0.2.0-preview.1

A preview of Conic with the interface redesigned after the
[VLC Redesign](https://www.figma.com/community/file/1691465999134370980/vlc-redesign)
Figma Community file by [Juxtopposed](https://www.youtube.com/@juxtopposed).
Playback still runs on VLC 3.0.24, which is bundled in each download.

## What's new

- New Home, player, picture in picture, menus and Settings, following the design, in Dark and Light themes.
- Settings that reach VLC: video, audio (equalizer, output, volume), subtitles, network and interface options are passed to the VLC engine. Each setting is marked as applying live, on the next open, or after a restart.
- Keyboard shortcuts you can change, shown in the right-click menu, with VLC 3's keys for volume, speed, chapters, Next Frame, delays and track cycling. Jump to Time (Ctrl+T) and About (Shift+F1).
- More ways to open media: several files or URLs at once, VLC's network protocols (rtsp, udp, smb and more), the command line, the clipboard (Ctrl+V) and dropped links. A subtitle file dropped on a playing video is added to it.
- Stereo mode, time-stretching, and the compressor's and spatializer's settings in Settings, Audio.
- VLC's video effects, live: rotation, colors, sharpening and more, a logo and marquee, and a crop in pixels. Snapshots (Shift+S), the A-B loop (Shift+L), program selection (X) and Hide UI (Ctrl+H).
- Subtitle files added while the media plays, queue search and sort, XSPF playlists, and Allow only one instance.
- A queue with track, title and chapter selection, plus resume from the last position.
- Messages, VLC's log, live, with a verbosity setting and Save, for problem reports.
- Linux x64: video plays through VA-API and DMA-BUF, decoded in hardware where VA-API is available, with VLC 3.0.24 bundled.

These builds are not signed.

- **Windows:** unzip anywhere and run `Conic.exe`. If SmartScreen stops it, choose **More info**, then **Run anyway**.
- **macOS:** unzip, move `Conic.app` to Applications, try to open it once, then choose **Open Anyway** in **System Settings > Privacy & Security**.
- **Linux:** extract the archive and run `./Conic`.

SHA-256 checksums are in `SHA256SUMS.txt`.

## Known limitations

- Conic is a one-off experiment and will not be maintained. To watch videos, use VLC.
- Missing VLC 3 features are listed in [Feature parity with VLC 3](https://github.com/mfkl/conic/blob/main/docs/FEATURE_PARITY.md).
- While a button has keyboard focus, keyboard shortcuts are ignored. Click the video first.
