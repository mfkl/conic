Conic 0.2.1

Conic is the VLC 3 player with the interface redesigned after the
[VLC Redesign](https://www.figma.com/community/file/1691465999134370980/vlc-redesign)
Figma Community file by [Juxtopposed](https://www.youtube.com/@juxtopposed).
Playback runs on VLC 3.0.24, which is bundled in each download.

This release fixes 0.2.0. What 0.2.0 added is described in its
[release notes](https://github.com/mfkl/conic/releases/tag/v0.2.0).

## What's fixed

- When a queue moves on to its next item, by itself or through Next, Previous or the queue, Conic follows that item. The title and Now Playing kept the first item's name, Recent listed only the first item, and the next items' positions were saved as the first item's Continue position.
- On macOS, a file named on the command line (`Conic.app/Contents/MacOS/Conic movie.mkv`) opens once. It was opened twice, and the window showed "Media could not be opened." with a 0:00 timeline while the file played. Several files open as one queue.
- The Intel macOS build no longer starts with a stale VLC plugin cache, which made VLC check every plugin again on each start.
- When the bundled VLC files are missing or damaged, the message names this platform's download. It always asked to extract the Windows x64 package again.

## Downloads

| File | Platform |
| --- | --- |
| `Conic-0.2.1-win-x64.zip` | Windows 10 and 11, x64 |
| `Conic-0.2.1-osx-arm64.zip` | macOS on Apple silicon |
| `Conic-0.2.1-osx-x64.zip` | macOS on Intel |
| `Conic-0.2.1-linux-x64.tar.gz` | Linux x64, glibc 2.38 or later (Ubuntu 24.04, Debian 13, Fedora 39) |

These builds are not signed.

- **Windows:** unzip anywhere and run `Conic.exe`. If SmartScreen stops it, choose **More info**, then **Run anyway**.
- **macOS:** unzip, move `Conic.app` to Applications, try to open it once, then choose **Open Anyway** in **System Settings > Privacy & Security**, or run `xattr -dr com.apple.quarantine /Applications/Conic.app` once in Terminal.
- **Linux:** extract the archive and run `./Conic`.

SHA-256 checksums are in `SHA256SUMS.txt`.

## Known limitations

- Missing VLC 3 features are listed in [Feature parity with VLC 3](https://github.com/mfkl/conic/blob/main/docs/FEATURE_PARITY.md).
- While a button has keyboard focus, keyboard shortcuts are ignored. Click the video first.
- Subtitles do not show in Home's mini player.
- Media that VLC can't open, such as a damaged file or a link that returns an error, leaves a black video area without an error message.
