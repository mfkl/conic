Conic 0.2.0-preview.2

A second preview of Conic, the VLC 3 player with the interface redesigned after the
[VLC Redesign](https://www.figma.com/community/file/1691465999134370980/vlc-redesign)
Figma Community file by [Juxtopposed](https://www.youtube.com/@juxtopposed).
Playback still runs on VLC 3.0.24, which is bundled in each download.

## What's new

- Home's mini player plays the video live instead of showing a still. It reuses the player's GPU surface, so there is no second decode and no copy. The thumbnail stays for audio, before the first frame and on the software video path.
- Windows: media keys, the volume flyout and the lock screen show and control what Conic plays, and the taskbar button gets a progress bar and Previous, Play/Pause and Next buttons.
- macOS: Control Center, the menu bar Now Playing widget and the media keys show and control Conic.
- Linux: Conic publishes what plays over MPRIS, so GNOME's and KDE's media controls, media keys and `playerctl` can play, pause, stop, seek and move through the queue.

These builds are not signed.

- **Windows:** unzip anywhere and run `Conic.exe`. If SmartScreen stops it, choose **More info**, then **Run anyway**.
- **macOS:** unzip, move `Conic.app` to Applications, try to open it once, then choose **Open Anyway** in **System Settings > Privacy & Security**, or run `xattr -dr com.apple.quarantine /Applications/Conic.app` once in Terminal.
- **Linux:** extract the archive and run `./Conic`.

SHA-256 checksums are in `SHA256SUMS.txt`.

## Known limitations

- Conic is a one-off experiment and will not be maintained. To watch videos, use VLC.
- Missing VLC 3 features are listed in [Feature parity with VLC 3](https://github.com/mfkl/conic/blob/main/docs/FEATURE_PARITY.md).
- While a button has keyboard focus, keyboard shortcuts are ignored. Click the video first.
- Subtitles do not show in Home's mini player.
